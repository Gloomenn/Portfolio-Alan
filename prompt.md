## Objetivo del rediseño

Crear una experiencia web basada en Full Screen Sections.

Cada apartado debe sentirse como una pantalla independiente que ocupa el viewport completo.

El usuario debe poder navegar entre las pantallas mediante:

- Scroll vertical suave.
- Flechas de navegación.
- Indicadores laterales.
- Navegación directa a cada sección.

Utiliza CSS Scroll Snap como base de navegación, JavaScript e Intersection Observer para detectar la sección activa y CSS para las animaciones.
